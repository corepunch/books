# Wondertown visual work

This directory contains Wondertown's art guides, references and authoring work.
The engine guide is [../../../AGENTS.md](../../../AGENTS.md).
Runtime JPEGs, cameras and prefabs live in [../rooms/](../rooms/).

- [LOCATION_BRIEFS.md](LOCATION_BRIEFS.md): implemented story geography.
- [SCENE_COMPOSITION.md](SCENE_COMPOSITION.md): room composition and fixed cameras.
- [ARTSTYLE.md](ARTSTYLE.md): approved Wondertown finish and palette.
- [CHARACTER_DESIGN_BIBLE.md](CHARACTER_DESIGN_BIBLE.md): locked cast identities.
- [PROCESS.md](PROCESS.md): current native interaction and image workflow.
- [RENDERING.md](RENDERING.md): offline Scener commands and validation.

`references/` holds character sheets. `tools/` holds the workshop source
generator. `archive/` preserves earlier art, source studies and superseded
prototype documentation; it is not loaded by the engine.
